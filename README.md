# java-racingcar-precourse


## 구현할 기능 목록

### controller
- [ ] 전체 게임의 실행 흐름을 관리한다.
  - [ ] 사용자 입력을 통해 자동차 이름과 시도 횟수를 전달받는다.
  - [ ] 입력받은 데이터를 기반으로 경주를 시작한다.
  - [ ] 경주 결과와 우승자를 출력한다.

### domain
- [ ] 자동차를 생성한다.
  - [ ] 자동차 이름이 5자 이하인지 확인한다.
  - [ ] 자동차 이름이 비어 있거나 공백만 포함되어 있지 않은지 확인한다.


- [ ] 자동차의 이동을 수행한다.
  - [ ] 0~9 사이의 랜덤 값을 생성한다.
  - [ ] 랜덤 값이 4 이상일 경우 자동차를 전진시킨다.


- [ ] 경주를 위한 유효성을 검증한다.
  - [ ] 경주에 참여하는 자동차가 둘 이상인지 확인한다.
  - [ ] 중복된 자동차 이름이 존재하지 않는지 검사한다.


- [ ] 시도 횟수의 유효성을 검증한다.
  - [ ] 시도할 횟수는 숫자여야 한다.
  - [ ] 시도할 횟수는 양수여야 한다.


- [ ] 경주 결과를 저장하고 우승자를 판별한다.
  - [ ] 가장 많이 전진한 자동차를 우승자로 결정한다.
  - [ ] 여러 명의 우승자가 있을 경우 모두 표시한다.

### service
- [ ] 각 라운드마다 자동차들의 이동을 반복 수행한다.
- [ ] 시도 횟수에 따라 경주를 자동으로 종료한다.
- [ ] 매 라운드의 진행 결과를 누적 저장한다.
- [ ] 우승자를 계산한다.

### constant
- [ ] Input 관련 안내 메시지 관리한다.
- [ ] Output 관련 출력 메시지 관리한다.
- [ ] Error 관련 예외 메시지 관리한다.

### view
- [ ] 자동차 이름을 입력받는다.
  - [ ] 자동차 이름을 쉼표(,)를 기준으로 구분한다.


- [ ] 시도할 횟수를 입력받는다.


- [ ] 경주 진행 결과를 출력한다.
  - [ ] 각 라운드별 자동차의 이동 결과를 출력한다.
  - [ ] 최종 우승자를 출력한다.
